ModGear версия 0.6.5

ModGear для Pawn

Плагин для SA-MP и компонент для open.mp: интерфейс лаунчера, тюнинг, хендлинг, звук в машинах и колонках, аксессуары. Все функции работают только для игроков, зашедших с лаунчера.

Функции с пометкой Alfa есть и в урезанной версии ModGearAlfa.

Установка

Плагин в plugins (SA-MP) или components (open.mp), все ModGear*.inc — в pawno/include (open.mp: qawno/include).

Подключение

#include <ModGear> — основное (лаунчер, сервер, утилиты). Остальное подключайте, что нужно: ModGear_Interface (худ, CEF, чат, диалоги, навигатор), ModGear_Player (игрок, аксессуары, оружие), ModGear_Vehicle (тюнинг, грязь, хендлинг), ModGear_World (объекты, частицы), ModGear_Media (музыка, видео), ModGear_Voice (голос, вебкамера), ModGear_NPC (педы). Версия инклуда должна совпадать с плагином.

Первый вызов

Когда игрок зашёл с лаунчера — SetPlayerLauncherStatus(playerid, true). До этого остальные функции ему ничего не отправляют.
